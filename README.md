# Catch The Jebi · 제비 잡기

제비뽑기 도구 위에 얹은 PC 전용 챌린지 게임.
날아다니는 제비 중 당첨 쪽지를 문 한 마리를 기준 시간 안에 잡아야 한다. 걸린 시간이 기록이다.

- 게임 스펙: [docs/SPEC.md](docs/SPEC.md)
- 원본 프로토타입(제비뽑기 아티팩트): https://claude.ai/artifact/W91Y5mAveyD137nUeqRNgK

## 상태

스펙 작성 단계. 코드는 아직 없다. 구현 순서는 스펙 13장 참고.

## 스택 (예정)

Vite + TypeScript · Canvas 2D · Vercel · Supabase · Kakao JS SDK · Umami
